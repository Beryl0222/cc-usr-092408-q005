# 国家教材版本接续

把教材版次、内容单元、法规依据、学校采用与勘误决定组织为**带有效区间的接续服务**：
只增事件流是唯一事实来源，按发生时间重放即可还原任意历史日期师生实际看到的文本。

## 能力

- **版次接续**：`release_edition` 登记版次与替代关系；版次切换形成左闭右开区间 `[from, to)`，旧日期永远还原旧文本。
- **三类载体分开解析**：正在印刷的批次（`print_batch`）、已采用的电子版（`electronic`）、教师备课引用（`lesson_prep`）各自维护内容引用与哈希。
- **历史文本还原**：`text_at(学校, 单元, 载体, 日期)` 返回该日的版次、内容哈希、所依据的法规与勘误；冻结区间返回 `FROZEN`，不返回文本。
- **勘误分级处置**：
  - 普通勘误（`normal`）→ `next_edition`：批准时不回贴已发布版次，下一个可用版次发布时自动编入并标注来源勘误；
  - 安全性/教学影响重大（`major`）→ `freeze`：立即冻结所有采用学校的受影响内容，按校排定确认截止点与升级点。
- **分层分批确认**：切换/解除前依次核对课程、学段、本地补充材料三层；可以按单元分批，三层齐备才解除对应内容；仍有冻结单元时禁止整体切换版次。
- **通知幂等**：同一通知同一批次再次确认返回原结果（`DUPLICATE`）；首次确认之后出现影响同批单元的更新勘误，则返回 `HELD_CONTENT_CHANGED`，内容保留待核、不解除。
- **教学事实不可改写**：授课记录（`TEACHING_FACT_RECORDED`）独立留存；存储拒绝改号、覆盖与版本回退，任何更正只能产生后继事件。
- **迟到问题**：`ISSUE_REPORTED` 同时记录实际发现时间与接收时间，重放顺序以发现时间入链。
- **可注入时钟与提醒**：`Clock`/`FixedClock`/`SystemClock`；到期、逾期、升级三级提醒的截止点固定在事件上，进程恢复（`EventStore.load`）后沿用原截止点并补发未达层级，已派发不重复。
- **监管追溯**：`trace_correction(勘误ID)` 从一条替换记录给出：仍受阻学校、各校每单元确认到哪一层、当前版次、本次生效选择所依据的法规与勘误版本（含生效版次）。

## 模块

| 文件 | 职责 |
| --- | --- |
| `src/clock.py` | 时钟协议、系统时钟、可推进的固定时钟 |
| `src/model.py` | 事件名、聚合类型、分级/载体/层次枚举、领域异常 |
| `src/store.py` | 只增事件存储：版本校验、JSON 导出与按序恢复 |
| `src/projections.py` | 事件重放、有效区间查询、冻结/确认判定、追溯与提醒读模型 |
| `src/service.py` | 命令侧：全部业务规则都在此转化为事件 |
| `src/validator.py` | 基础事件信封校验（沿用既有约定） |
| `contracts/domain.schema.json` | 领域事件名称与聚合类型契约 |
| `tests/` | 时间线、勘误分级、分层确认、时钟/恢复、监管追溯共 26 个用例 |

## 领域边界

事件一旦被接收，其标识、发生时间和版本不被原地改写；业务更正产生后继记录（如新版次内容绑定、`HELD_CONTENT_CHANGED` 待核记录）。
冻结、解除、版次切换都保留完整区间：今天解除不会"追溯洗白"昨天的冻结，切换版次也不会改写切换前的文本。

## 本地检查

```bash
python3 -m unittest discover -s tests
python3 -m compileall -q src tests
```

均在单个 Linux 应用容器内执行，无需外部服务。
